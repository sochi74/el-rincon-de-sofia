# El Rincón de Sofía 🛋️
Un juego de vida acogedor: Sofía vive en su casita y su amigo real.fixer viene de visita.
Visión: un mundo de fantasía mágico y relajante, visto desde arriba, para construir, explorar y hacer amigos.

## Cómo jugar
- En internet: https://sochi74.github.io/el-rincon-de-sofia/
- En tu computadora: abre index.html

## Personajes
- 💗 Sofía: dormilona, glotona y creativa; le encanta ver tele. "Pizza and a movie!" Lleva su Princess crown 👑
- 🧢 real.fixer: tranquilo, creativo y conversador; le encanta charlar. "Let's fix it." Vive en una carpa junto al río. Su gatito naranja se llama Krohna 🐱
- 🧚 Lumi: hada vecina, energética, bromista y fiestera; vive en una casita en un árbol del bosque y pasea volando. "¡A volar se ha dicho!"
- 🧛 Vladi: vampiro vecino que le tiene miedo a la oscuridad; duerme de día en su castillito y de noche pasea abrazando su osito. "Is it dark in here?"

## Para el Modo Planear (continuación)
- Quiénes: Sofía es la dueña del juego y decide todo. Robert (real.fixer) le dio las instrucciones del arquitecto (su archivo de instrucciones), pero no está presente en las sesiones. Las decisiones grandes se hablan con Robert.
- Computadora de Sofía: Windows con terminal Linux (WSL, Ubuntu). Carpeta del juego: ~/juegos/el-rincon-de-sofia. Usuario de GitHub: sochi74. No hace falta volver a preguntarle qué computadora usa.
- Comandos que funcionan en su terminal:
  - Actualizar el repo local: cd ~/juegos/el-rincon-de-sofia && git checkout main && git pull --prune
  - Abrir Claude Code: cd ~/juegos/el-rincon-de-sofia && claude
  - Copiar el informe: gh pr view --json title,body,files | iconv -t UTF-16LE | clip.exe (así salen bien los acentos; su gh es viejo y "gh pr view" solo da error)
  - Hacer merge: gh pr merge --squash --delete-branch
  - Ver si hay pull requests abiertos: gh pr list
  - Abrir el juego desde Claude Code: explorer.exe index.html
  - Ver los cambios en el link: recargar con Ctrl + F5
  - Copiar las biblias para un chat nuevo: cd ~/juegos/el-rincon-de-sofia && cat CLAUDE.md README.md ROADMAP.md CHANGELOG.md CHARACTERS.md | iconv -t UTF-16LE | clip.exe
- Forma de trabajar que le gusta a Sofía:
  - Preguntas con botones de opción múltiple, siempre con la opción de escribir su propia idea.
  - Antes de cada hito, ella diseña los detalles (qué flores, qué recetas, qué regalos) con botones.
  - Un mini quiz de inglés en cada hito, con botones, antes de revisar el informe.
  - Recordarle: no tomar captura de pantalla después de copiar el informe (la captura reemplaza lo copiado), no pegar el prompt en el chat del Modo Planear (va dentro de Claude Code), y no escribir /exit hasta que Claude Code se lo diga.
  - Revisión honesta de cada informe. Cuando se acumulan problemas conocidos, se ofrece un hito de pulido.
- Regalos desbloqueados con estrellas (uno nuevo cada 5 ⭐):

### Proceso de traspaso entre arquitectos (estándar)
Cuándo: cuando el chat del Modo Planear se vuelve muy largo (más o menos cada 6 a 8 hitos), o cuando Sofía vuelve otro día.
1. El arquitecto actual le da a Sofía un prompt de continuidad (solo documentos) que pone al día esta sección (estrellas, regalos, siguiente paso, decisiones pendientes) y la lista "Problemas conocidos actuales" de CHANGELOG.md, y revisa que las biblias coincidan con el código.
2. Revisión y merge, como cualquier hito.
3. Sofía actualiza su repo local y copia las biblias con el comando de arriba.
4. En un chat nuevo pega, en este orden: las instrucciones de Robert, sus cinco biblias y el mensaje de traspaso del arquitecto anterior.
5. El nuevo arquitecto entra en modo continuación: lee todo, saluda a Sofía por su nombre, resume en 3 líneas dónde está el juego, muestra el marcador (hitos y ⭐) y pregunta si construir el siguiente hito o seguir diseñando.
Además, en cada hito, el prompt pide actualizar en esta sección las estrellas, los regalos y el siguiente paso, para que siempre esté lista para un traspaso.
